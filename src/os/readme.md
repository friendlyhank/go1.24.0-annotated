### 💻 二、`src/os`：操作系统交互接口
此目录实现跨平台系统操作，封装了文件、进程、环境变量等底层功能。
1. **文件与目录操作**
    - 创建/删除：`Create()`、`Remove()`、`MkdirAll()`；
    - 元数据管理：`Chmod()`（修改权限）、`Chown()`（修改所有者）；
    - 路径处理：`Getwd()`（获取工作目录）、`ExpandEnv()`（扩展环境变量路径）。
2. **进程控制**
    - 进程信息：`Getpid()`（当前进程ID）、`Getppid()`（父进程ID）；
    - 进程管理：`Exit()`（终止程序）、`Exec()`（执行外部命令）。
3. **环境变量访问**  
   `Getenv()`、`Setenv()`、`Environ()`。
4. **标准I/O抽象**  
   提供`Stdin`、`Stdout`、`Stderr`标准流对象。
> ⚠️ **依赖关系**：`os`包基于`syscall`包实现跨平台适配，处理系统调用差异。
