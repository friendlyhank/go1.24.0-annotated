### 📦 一、`src/builtin`：内置语言元素的定义
此目录仅包含`builtin.go`文件，定义了Go语言的内置标识符（无需导入即可使用），**仅供编译器识别**，无实际运行时逻辑。
1. **内置类型**  
   基础类型（如`int`、`string`）、复合类型（如`error`接口）及别名（如`byte`、`rune`）。
2. **常量与变量**  
   如`true`、`false`、`iota`、`nil`。
3. **核心内置函数**  
   包括：
    - 内存管理：`make`（初始化切片/映射/通道）、`new`（分配内存）；
    - 数据操作：`append`（切片追加）、`copy`（切片复制）、`delete`（映射删除）；
    - 运行时控制：`panic`、`recover`（异常处理）、`len`/`cap`（获取长度/容量）。
> 💡 **关键特点**：这些函数**无具体实现代码**，由编译器直接转换为底层操作（如`len`编译期内联展开）。
